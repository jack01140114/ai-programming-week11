# 12주차 성적 데이터 분석

## 데이터

출처는 한국기술교육대학교 「AI 협업 프로그래밍」 12주차 실습 배포 자료입니다.

| 파일 | 내용 |
| --- | --- |
| `scores_2026.csv` | 114행 5열, UTF-8. 배포 자료의 학번·이름을 일관된 대체값으로 바꿨습니다. 반, 과목, 점수, 결측과 중복 구조를 보존했습니다. |
| `mini.csv` | 산술 검산용 10행, UTF-8. |

열은 학번(학생 식별 번호), 이름(학생 이름), 반(1반 또는 2반), 과목(수학·영어·프로그래밍), 점수(0~100점)입니다. 점수가 없는 행은 제외합니다. 0점이나 평균을 넣으면 확인되지 않은 점수가 반 평균에 반영되기 때문입니다. 다섯 열이 모두 같은 중복은 첫 행만 남기고, 반·과목의 앞뒤 공백을 제거한 뒤 0~100점 범위를 벗어난 행을 제외합니다.

## 실행과 검증

저장소 루트에서 실행합니다.

```sh
python -m pip install pandas pytest
python week12/analysis.py
python -m pytest -q week12/test_analysis.py
```

114행에서 결측 6행, 완전 중복 4행, 범위 밖 4행을 제외하면 100행이 남습니다. 반별 점수 합은 7,484점이고, 10행짜리 검산용 파일의 정제 결과는 7행입니다. 검산용 파일의 평균은 1반 80.0점, 2반 70.0점입니다.

## 결론

정제한 100건을 실제 과목 구성대로 합쳐 비교하면 1반이 평균 78.24점으로 2반의 71.44점보다 6.80점 높습니다. 같은 과목끼리 비교하면 수학은 64 대 60점, 영어는 79 대 76점, 프로그래밍은 88 대 84점으로 세 과목 모두 2반이 높습니다. 평균이 높은 프로그래밍 기록은 1반에 30건, 2반에 8건 있고, 평균이 낮은 수학 기록은 1반에 8건, 2반에 30건 있습니다. 전체 평균을 기준으로 하면 1반, 같은 과목 내 평균을 기준으로 하면 2반이 더 잘했습니다.
